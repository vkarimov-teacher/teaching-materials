Key Concepts

Port states (open, closed, filtered), the three-way handshake, service fingerprinting, and OS detection methodology.

Port States Reference

  • open — An application is actively accepting connections on this port
  • closed — Port is reachable but no application is listening (responds with RST)
  • filtered — Packet filtering (firewall) prevents probe from reaching the port
  • open|filtered — Unable to determine if port is open or filtered (no response)

Service Enumeration

After discovering open ports, enumeration extracts detailed information: usernames, shares, DNS records, SNMP data, and more.

TCP 53 DNS Enumeration

Zone transfers (AXFR), reverse lookups, subdomain brute-forcing, and DNS cache snooping to map the target's domain infrastructure.

TCP 445 SMB Enumeration

Listing shared folders, enumerating users via RID cycling, checking null sessions, and identifying accessible resources.

UDP 161 SNMP Enumeration

Walking OID trees with community strings to extract system info, network interfaces, routing tables, and installed software.

$ snmpwalk -v2c -c public 10.10.10.40 SNMPv2-MIB::sysDescr.0 = Hardware: Intel64 x64 Windows Server 2019 Build 17763 SNMPv2-MIB::sysUpTime.0 = Timeticks: (5765432) 16:02:34.32 IF-MIB::ifDescr.1 = Ethernet0 IF-MIB::ifPhysAddress.1 = 0a:1b:2c:3d:4e:5f HOST-RESOURCES-MIB::hrSWInstalledName.1 = Microsoft SQL Server 2019

TCP 25 SMTP Enumeration

Using VRFY and EXPN commands to verify email addresses and discover valid user accounts on the mail server.

$ nc -nv 10.10.10.30 25 220 mail.lab.local ESMTP Postfix VRFY admin 252 2.0.0 admin VRFY root 252 2.0.0 root VRFY guest 550 5.1.1 <guest>: Recipient address rejected VRFY backup 252 2.0.0 backup

Enumeration Methodology

  • Start with broad port scans to identify listening services
  • Banner grab each service to identify version and technology
  • Check for anonymous/null authentication on every service
  • Enumerate users, shares, and directory structures
  • Search for known vulnerabilities based on version information
  • Document every finding — missed details cost time later
